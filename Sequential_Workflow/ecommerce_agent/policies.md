# Ahmed Clothing: Policies

## Delivery kitne din mein hoti hai?
Lahore, Karachi aur Islamabad mein delivery 2 se 4 working din mein hoti hai. Baaqi shehron mein 3 se 5 working din lagte hain. Order dispatch hone par aap ko tracking number WhatsApp par bhej diya jata hai.

## Delivery charges kitne hain?
Poore Pakistan mein delivery charges Rs 250 hain. Rs 5,000 se zyada ke order par delivery free hai.

## Return policy kya hai?
Delivery ke 7 din ke andar return ho sakta hai. Item unused hona chahiye aur original tags aur packing ke saath wapis aana chahiye. 7 din guzarne ke baad return nahi liya jata.

## Refund policy kya hai?
Refund sirf unused items par hota hai. Return ka item humein mil jane aur check hone ke baad refund 5 se 7 working din mein original payment method par bhej diya jata hai. Pehne ya dhule hue items par refund nahi hota.

## Exchange (size ya rang badalna) kaise hota hai?
Size ya rang ka exchange delivery ke 7 din ke andar ho sakta hai, agar wo size ya rang stock mein ho. Item unused aur tags ke saath hona chahiye. Exchange ke liye order number aur naya size WhatsApp par bhej dein.

## Payment ke kaun se tareeqe hain?
Cash on Delivery (COD), Easypaisa, JazzCash aur bank transfer ke zariye payment ki ja sakti hai.

## Order track kaise karein?
Order dispatch hone par tracking number aur courier ka naam aap ko WhatsApp par bhej diya jata hai. Track karne ke liye courier ki website ya app par wo number daal dein.

## Order cancel ya change kaise karein?
Order dispatch hone se pehle cancel ya change ho sakta hai. Jaldi karein aur order number WhatsApp par bhej dein. Dispatch ke baad cancel nahi hota, aap return policy ke mutabiq return kar sakte hain.

## Item kharab, phata hua ya galat aaya to kya karein?
Parcel milne ke 24 ghante ke andar item ki photo aur order number WhatsApp par bhej dein. Hamari team jaanch kar ke replacement ya refund ka tareeqa batayegi.

## Size guide kya hai? Size kaise chunein?
Kurta aur shalwar kameez ka chest size (inch mein): S 38, M 40, L 42, XL 44, XXL 46. Agar aap do sizes ke darmiyan hain to bara size chunein. Jeans ka size waist ke inch ke mutabiq hai (28 se 36).

## Discount ya sale kab hoti hai?
Kuch products par sale chal rahi hai, un ki sale qeemat product ki tafseel mein likhi hoti hai. Zyada quantity (bulk) ke order par discount ke liye humari team se rabta karein.
